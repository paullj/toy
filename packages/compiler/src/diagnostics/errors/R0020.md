# R0020: target import private

`core/target` names what the program is built for: its consts `os` (`.macos`,
`.linux`), `arch` (`.aarch64`, `.x86_64`) and `profile` (`.debug`, `.release`) come
from the build's target and profile. Only a `core/` module may import it. The standard
library offers no target-specific API, so a program reads the same `std/` surface on
every target, and a `std/` or user module that imports `core/target` gets this error at
the import path. `--dev-core-imports` does not lift it.

```
import core/target    # error: module 'core/target' is private to core; only a
                      # core/ module may import it
fn main() -> int {
    return match target.os { .macos -> 0, .linux -> 1 }
}
```

Fixes:

- Use the `std/` API, which works the same on every target.
- If you are extending the standard library, read the target in a `core/` module and
  give `std/` one function over it.
