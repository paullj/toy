# T0084: constant depends on itself

A constant's value is worked out while compiling, from its initializer. When that
initializer names the constant itself, directly or through other constants, the value
would have to be known before it is worked out, so it has none. The error points at the
use that closes the cycle and spells the cycle out.

```
A :=: B + 1
B :=: A * 2   # error: constant 'A' depends on itself: A -> B -> A
N :=: N       # error: constant 'N' depends on itself: N -> N
```

Fixes:

- Write one of the values out, so the chain ends: `B :=: 4`.
- If the two values really do depend on each other, compute them in a function at run
  time instead.
