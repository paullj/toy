# T0048: non-exhaustive match

A `match`, or the match form of `when`, does not cover every possible value of its
scrutinee. An enum match must handle each variant, a bool match both `true` and
`false`, and an int match needs a `_` arm. The diagnostic lists the variants that are
missing. A `when` must cover them all even though its scrutinee is a constant, so a
new variant is an error at each `when` over its enum.

```
enum Shape {
    Empty,
    Circle(int)
}

fn area(s: Shape) -> int {
    match s {   // error: non-exhaustive match: missing variant 'Empty'; add the missing arm(s) or a '_' arm
        .Circle(r) -> r * r
    }
}
```

Fixes:

- Add an arm for each missing variant or value.
- Add a `_ -> ...` catch-all arm last.
