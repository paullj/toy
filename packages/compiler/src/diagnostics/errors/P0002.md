# P0002: expected expression

An expression was required here — for example after `return`, inside a call
argument, or on the right of an operator — but the parser found a token that
cannot begin an expression.

Supply a value (a literal, a name, or a parenthesised expression) at this
position, or remove the stray token.

A declaration (`x :=`, `x: T =`, `N :=:`, `N: T =:`) whose value is missing is this
error at its operator. Its value may start on the next line, but not when that line
starts a declaration of its own or a token no expression starts with:

```
fn main() -> int {
    x :=          # error: expected a value on the same line as the declaration
    y := 2
    z :=
        3         # fine: the value continues on the next line
    y + z
}
```
