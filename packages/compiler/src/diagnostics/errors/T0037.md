# T0037: extern invalid type

An `extern fn` may only use the C-ABI types the backend can marshal across the
AAPCS64 boundary: `int` (any width), `rawptr` (a C `void*`), `cstr` (a C
`const char*`), `bool`, `float` (a C `double`), `float32` (a C `float`) and an
`extern struct`. A parameter or return type outside that set (a plain struct, an enum,
a `Vec`) is rejected. The same set, without the `extern` functions' `str`, is what an
`extern struct`'s fields may be, and a `mut` extern param, which C gets as a pointer,
must be an `extern struct`. A param of a function type is a C callback: its own params
and return must be in that set too (see **T0080** for what may be passed there), and an
extern cannot return a function type.

```
extern fn frobnicate(p: Point) -> int   // error: a plain struct has no C layout
extern fn puts(s: str) -> int32         // error: a str is not a C string
extern struct Named { name: str }       // error: a str field is not a C type
extern fn bump(mut n: int)              // error: only an extern struct passes by pointer
extern fn each(cb: fn(str) -> int)      // error: a callback's params are C types too
```

A `str` is a pointer and a length with no NUL at the end, so a C function that reads
a `const char*` would run past it. Only the bundled `core/` modules may use a `str`
in an extern signature, where it spreads to a C `(const char* buf, size_t len)` pair
for functions such as `write`.

Fixes:

- For a C string, declare the param or return as `cstr`. With `import std/ffi`, pass
  `s.to_cstr()` (a NUL-terminated copy) and turn a returned one into a `str` with
  `c.to_str()`:

```
import std/ffi

extern fn puts(s: cstr) -> int32

fn main() -> int {
    unsafe { puts("hi".to_cstr()) }
    return 0
}
```

- For a C struct, declare it `extern struct S { .. }` with C-typed fields; it passes by
  value, or by pointer as a `mut` param.
- Pass a `rawptr` (a C `void*`) or a scalar for anything else.
- Restrict parameters and the return type to `int`, `float`, `float32`, `rawptr`, `cstr`,
  `bool`, or an extern struct.
