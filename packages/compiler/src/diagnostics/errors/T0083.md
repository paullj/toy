# T0083: constant not known at compile time

A constant (`N :=: e`) has no storage: every use of `N` is replaced by its value, so
the compiler must work that value out while it compiles. The initializer may be an
integer literal, or literals joined by the integer operators (`+ - * / % & | ^`, the
wrapping `+% -% *%`, unary `-` and `~`). Anything else is rejected, as is an expression
that cannot be evaluated, such as a division by zero.

```
fn ten() -> int { 10 }

N :=: ten()     # error: a call runs only when the program runs
M :=: 1 / 0     # error: a division by zero has no value
```

Fixes:

- Write the value out: `N :=: 10`.
- Use a variable inside a function when the value is only known at run time:
  `n := ten()`.
