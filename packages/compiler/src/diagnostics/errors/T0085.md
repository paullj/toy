# T0085: when condition not known at compile time

A `when` chooses its arm while the program compiles, so its condition, or the scrutinee
and each arm guard of its match form, must have a value then: literals, constants (`N :=: e`), an enum's unit variant, and the operators over
them, as in a constant's initializer. A variable, a parameter or a call has a value only
when the program runs. A payload binding (`n` in `.some(n)`) has a type but no value,
and is accepted: no constant holds a payload, so its arm is never taken.

```
DEBUG :=: false

fn f(n: int) -> int {
    when DEBUG { 1 } else { 2 }    # fine: DEBUG is a constant
    when n > 0 { 1 } else { 2 }    # error: n is known only at run time
    when DEBUG {
        true -> 1
        false -> 2                  # fine: the match form, on a constant
    }
    when n { _ -> 1 }               # error: n is known only at run time
}
```

Fixes:

- Use `if` or `match` when the choice depends on a value the program computes.
- Make the value a constant: `N :=: 4`.
