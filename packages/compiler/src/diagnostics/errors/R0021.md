# R0021: emission unsupported

`toy build` names a target that toy can check a program for but cannot yet emit
code for. Today toy emits code for `aarch64-macos` and `aarch64-linux`;
`x86_64-linux` is checked but not built. The error comes before
any work is done, and it is a usage error (exit 2). (`toy run` for a target other
than the host fails before this, with its own error.)

```
$ toy build --target x86_64-linux main.toy
error[R0021]: code emission for x86_64-linux is not supported yet
  = help: 'toy check --target x86_64-linux' checks the program for it
```

Fixes:

- Check the program for the target instead: `toy check --target x86_64-linux main.toy`
  reads `core/target` as that target and checks the program as its build would.
- Build for a target toy emits: leave out `--target`, or pass `--target aarch64-macos` or
  `--target aarch64-linux`.
