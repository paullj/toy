# T0086: compile_error

`compile_error("msg")` stops the build with `msg`. It is an error wherever the program
compiles it: anywhere but an arm of a `when` that the constants did not choose. In an arm
not taken it does nothing, so it marks the targets or settings a `when` does not support.
Its type is `never`, so it fits an arm of any type. The message is a string literal.

A function's body always counts as compiled, even when nothing calls the function, so
`toy check` and `toy build` report the same errors whatever calls what. The exception is
a generic function whose type parameters have no bounds: its body is checked once per
instance, so in one that nothing instantiates `compile_error` reports nothing.

```
LEVEL :=: 2

WIDTH :=: when LEVEL {
    1 -> 32
    2 -> 64
    _ -> compile_error("LEVEL must be 1 or 2")   # error only when LEVEL is neither
}

fn width() -> int {
    when LEVEL > 0 { WIDTH } else { compile_error("LEVEL must be positive") }
}

fn todo() -> int {
    compile_error("todo is not written yet")      # error: not in a when arm
}
```

Fixes:

- Build for a target or profile that an arm without `compile_error` handles.
- Add the arm that handles this target or setting.
