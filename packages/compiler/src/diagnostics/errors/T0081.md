# T0081: vararg not promoted

A C variadic function (`extern fn printf(f: cstr, ...) -> int32`) reads each argument
after its named params as C reads a `...` argument: C has already promoted it, so it is
a 64-bit integer, a `double`, or a pointer, each in its own 8-byte stack slot. Toy does
not promote for you, so an extra argument must already be one of:

- `int`, `int64` or `uint64` (C `long`, `long long`, `size_t`, and what `%d` reads too);
- `float` (C `double`, what `%f` and `%g` read);
- `cstr` (`%s`);
- `rawptr` (`%p`, or any pointer argument).

Anything else is rejected at the argument: a narrower integer, `bool`, `float32`, a `str`,
a struct, an enum or any other toy value.

```
extern fn printf(f: cstr, ...) -> int32

fn main() -> int {
    n: int32 = 3
    x: float32 = 1.5
    unsafe { printf("%d\n".to_cstr(), n) }      // error: int32 is not promoted
    unsafe { printf("%f\n".to_cstr(), x) }      // error: float32 is not promoted
    unsafe { printf("%s\n".to_cstr(), "hi") }   // error: a str is not a C string
    return 0
}
```

Fixes:

- Widen a narrow integer first: `w: int = n.into()`, then pass `w`.
- Convert a `float32` to `float` the same way: `d: float = x.into()`.
- Pass a `bool` as an int: `if b { 1 } else { 0 }`.
- Pass a `str` as a C string: `s.to_cstr()` (std/ffi).
