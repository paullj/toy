# T0087: negation of an unsigned type

Unary `-` does not apply to an unsigned type (`uint`, `uint8`, `uint16`, `uint32`,
`uint64`), whether the operand is a variable or a constant. Its only result that fits the
type is `-0`, so it would be an overflow for every other value.

```
LIMIT: uint8 =: 200

fn flip(x: uint8) -> uint8 {
    -x            # error: cannot negate unsigned type 'uint8'
}

fn low() -> uint8 {
    -LIMIT        # error: the same for a constant
}
```

Fixes:

- Use `0 -% x` for the wrapping negation: `0 -% x` with `x: uint8 = 1` is 255 in every
  build.
- Use a signed type if the value can be negative.

A negative literal for an unsigned type, such as `v: uint8 = -1`, is a literal out of
range instead (T0034).
