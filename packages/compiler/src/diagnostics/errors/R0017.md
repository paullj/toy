# R0017: not a shared library

The library file was found but cannot be linked: it is not a shared library the target
loads. The error says why. On macOS: it is not a Mach-O file, it is not built for
arm64, it is an executable or a bundle rather than a shared library, or it has no
install name (`LC_ID_DYLIB`). toy reads the install name and versions from the
library, so the binary it writes records where the loader will find it at run time.

```
// vendor/libfoo.dylib is really a text file, or an x86_64-only build
extern "./vendor/libfoo.dylib" { fn foo() }   // error: library './vendor/libfoo.dylib'
                                             // cannot be linked: ...: it is not built for arm64
```

On macOS a universal (fat) library works when it holds an arm64 slice.

Fixes:

- Rebuild the library as a shared library for the target (on arm64 macOS,
  `cc -shared -arch arm64`).
- Check that the path names the library and not another file.
